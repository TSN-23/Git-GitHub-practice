# *Git Commands:*

- git init .  -> this convert a folder into a repository..
- git status  -> it show the current status..
- git add filename -> git starts tracking this file through this command..
- git commit -m"msg" -> to save any changes
- git log -> Description about the commits
- git log --oneline -> Description about the commits 
- git checkout -   -> it take back to the master/or main branch form any other branch
- git checkout master/main -> same as git checkout -
- git checkout -b"New Brach name" -> Use to Creat new branch
- git checkout branchname -> it will move to this branchname
- git config --local user.emails email  -> set user email
- git config --local user.name name  -> set user name 
- git merge branchname  -> this will merge the current branch with "branchname" branch
- git remote add origin URL -> this connects the gitHub repository to the terminal
- git push -u origin branchname -> this push the code in the "branchname" branch in github repository
